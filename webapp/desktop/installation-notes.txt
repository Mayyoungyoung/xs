墨脉 · AI 小说创作软件

安装位置可在下一页选择，例如 D:\应用\墨脉。

首次启动后，点击“模型设置 → 小说存储位置 → 更改位置并迁移”，可以选择 D 盘或其他位置的空文件夹。软件会迁移小说、章节、世界线、版本、自动备份和本机加密的模型密钥，校验成功后使用新位置。原目录暂时保留。

软件可离线编辑与保存。使用 AI 创作时，请在设置中填写自己的 DeepSeek API Key；模型服务按您自己的账户计费。

从网页版迁入：网页版书架导出完整备份，再在桌面版书架导入项目。

卸载软件不会删除独立保存的小说资料。请定期导出备份；切勿在软件运行时手动改写资料文件。

此安装包仅包含应用程序，不包含作者的小说或 API 密钥。
